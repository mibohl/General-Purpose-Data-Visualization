Can in-context tabular learning beat TCRdist on unseen epitopes?

Short answer: no, not where it counts. With a few labeled TCRs for a brand-new epitope, TabPFN v2 and NVIDIA Kumo Tabular (S) do not beat the cheap TCRdist nearest-neighbour baseline. They only pull ahead once the support set is large.

Given exactly TCRdist's inputs — germline CDR1/CDR2/CDR2.5 + CDR3 for both chains — the tabular models reach parity by k=50, but TCRdist still wins at k=20. Representation was most of the story; the learner was not the limiter. Sections 07–09.

01

The task

One task = one epitope. The support set is k labeled TCRs for that epitope; the query is the rest. Leave-one-epitope-out, so every evaluated epitope is unseen by any cross-epitope training. Because the epitope is constant within a task, the model encodes the TCR only. Negatives come in two flavours, reported separately: (a) healthy-donor background TCRs and (b) TCRs that bind other epitopes — the honest, harder choice.

06

Is the comparison fair?

It is fair as a protocol, but it is a comparison of pipelines, not of models — and two asymmetries pull in opposite directions.

Fair by construction

  • Identical splits, seeds, query TCRs, labels and metric for every method.
  • The same 90%-identity cluster-aware anti-leakage — which matters most for a nearest-neighbour scorer — applied to all.
  • Beta-chain only in the primary run; no tuning on held-out epitopes; same CPU.

Not a clean model-vs-model test

  • Tilts against TCRdist: it scores on support binders only, ignoring the negatives the tabular models learn from — yet still wins at low k.
  • Tilts for TCRdist: its metric uses germline CDR1/CDR2 loops; the tabular models got only generic Atchley CDR3β + a target-encoded V/J label. "Kumo loses" is entangled with "this featurization is weak."
  • Δ uses the better of NN/k-NN per epitope — a mild best-of-two flattering of the baseline.
What this licenses: with a frozen generic CDR3β featurization, a tabular foundation model does not beat TCRdist's domain distance for unseen-epitope few-shot, at comparable cost. It does not license "the models are worse" — that needs matched inputs (feed the tabular models the same CDR1/CDR2, or run TCRdist on paired chains). The follow-up below runs exactly that test.

The fair rematch: matched inputs

Give the tabular models exactly the information TCRdist uses — Atchley over the germline CDR1, CDR2, CDR2.5 and CDR3 loops of both chains, read from tcrdist3's own germline tables (395 features), on the identical splits, seeds and clustering. TCRdist is given its best configuration per epitope: notably, paired TCRdist is weaker than beta-only here — equal-weighting a noisier α-chain dilutes its nearest-neighbour distance — so it is not handicapped.

Headroom: how high is the ceiling?

Headroom = oracle − zero-shot, per epitope. The oracle is the best within-epitope model under cluster-aware cross-validation on all of an epitope's labels; zero-shot trains on every other epitope and is applied with no target labels. The gap is the most any in-context head could ever capture.

09

Is there anything to meta-learn?

If the per-epitope binding functions were similar, a pooled model with no epitope conditioning would match the per-epitope models, and an in-context head could amortize the shared structure. They are not.

per-epitope
0.816

Each epitope is learnable

A model fit on one epitope's own labels (cross-validated) reaches 0.82 AUROC. The within-task signal is strong.

pooled
0.079

Pooling inverts

One model over all epitopes with no conditioning scores 0.08 — far below chance. Under honest negatives the same TCR is a positive for its epitope and a negative for others, so the boundary is self-contradictory.

coefficients
≈ 0

Orthogonal functions

Per-epitope ridge coefficient vectors have pairwise cosine similarity ~0 (−0.18 to +0.20). The binding rules don't overlap.

Each epitope is its own problem. There is little shared structure to amortize across tasks, so the value of in-context learning here is within-task fitting, not meta-learned transfer. It is also why more capacity or a better prior won't close the k=20 gap — only more target labels will.

Methods & provenance

Data

IMMREP22 benchmark — 11 epitopes with ≥100 positives, paired α/β. Positives are VDJdb-derived; background negatives are healthy-donor CD8 TCRs. source ↗

Clonal control

Exact duplicates collapsed; CDR3β clustered at 90% identity; splits made by cluster so no clone spans support/query. GILGFVFTL: 680 → 444 unique → 282 clusters.

Features (frozen)

Primary: 100 Atchley factors over CDR3β + length + target-encoded V/J = 103. Fair rematch: Atchley over germline CDR1/CDR2/CDR2.5 + CDR3, both chains, from tcrdist3's tables = 395. No epitope features within a task.

Protocol

k ∈ {20, 50, 200}, 5 seeds, both negative schemes. TabPFN 2.0.9 (ungated v2 weights), Kumo via structured-data-models 0.3.0, tcrdist3. Per-epitope, never pooled.
