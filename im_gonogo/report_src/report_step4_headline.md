With 20 to 50 reference precursors, ridge and TabPFN v2 residual models match a 2-parameter affine fix (within 2.5 %). TabPFN gains 10.6 % only at k = 1000, and a non-adaptive control (a residual model trained once on the other studies, then affine) recovers all but 2.6 % of that gain. The cross-study residual after affine is about twice what replicate noise alone produces, so some study × peptide residual is real. But it is not a warp (a noise-only null reproduces the 0.14 gap exactly), and peptide features explain only 6 % of it (median within-study CV R²; 13 % without multi-conformers), with no transfer between studies. There is no learnable structure big enough to justify a meta-trained in-context model.
